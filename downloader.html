⚙️ Backend Setup — How to Self-Host
This frontend calls a local yt-dlp backend API at http://localhost:5000.
Run the included Python backend server to enable downloads:
# Install dependencies
pip install yt-dlp flask flask-cors

# Run the backend server
python grabmax_server.py
